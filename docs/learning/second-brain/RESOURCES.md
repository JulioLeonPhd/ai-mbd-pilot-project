# Second Brain Resources

## Knowledge

- [Tiago Forte: 9 Biggest Myths and Misconceptions About Building a Second Brain](https://fortelabs.com/blog/9-biggest-myths-and-misconceptions-about-basb/)
  Describes CODE as capture, organize, distill, and express, and frames personal
  knowledge management as distributed practice rather than a single app. Use
  for vocabulary and practice ideas; this does not establish the identity or
  authority of the unidentified expert mentioned in the original note.
- [Andy Matuschak: Evergreen notes](https://notes.andymatuschak.org/Evergreen_notes)
  Describes evolving, atomic, concept-oriented notes connected by links. Use
  when considering how a recovery note can stay useful across sessions; it is a
  note-taking perspective, not a project requirement.
- [Obsidian Help: How Obsidian stores data](https://help.obsidian.md/Files+and+folders/How+Obsidian+stores+data)
  Explains that Obsidian stores notes as local Markdown files in a vault folder.
  Use to understand this app’s storage model, not as a reason to migrate or
  adopt it.

## Wisdom (Communities)

- [Obsidian Forum](https://forum.obsidian.md/)
  Community discussions can surface practical note-maintenance patterns and
  app-specific questions. Treat posts as experience and opinion, not
  authoritative evidence for this project.

## Gaps

- The value of a shared AI workspace for this project has not been measured.
  The three-session experiment should record recovery time and maintenance
  cost before drawing conclusions.
