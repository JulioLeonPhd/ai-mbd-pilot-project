# Domain docs

This repo uses a single context: `CONTEXT.md` at the root and
system-wide decisions in `docs/adr/`.

Before exploring a topic, read `CONTEXT.md` and the relevant ADRs.
Use the glossary's terms in issues, proposals, hypotheses, and tests.
If a needed concept is missing, note the gap for domain modeling.
Surface any proposed change that conflicts with an ADR explicitly.
